# 分享版驗收紀錄

驗收日期：2026-10-28。所有範例及 HTTP 保存測試使用隔離合成資料。

- 46 個測試模組：375 項通過；7 項企鵝裝飾測試略過，原因是該素材不隨包。逐模組結果見 [VALIDATION.json](VALIDATION.json)。
- 涵蓋來源失敗不報零、DT 分頁、CVE/finding/專案口徑、來信跨日與未回答問題、保存讀回、重開、冪等、修訂衝突、備份還原、報告版本及過期資料。
- 新分享版 Windows PowerShell 啟動器以 `-NoOpen -NoPause` 實測 exit 0，經既有 Kali WSL 回傳新複本的 localhost URL；沒有開啟瀏覽器或模擬滑鼠雙擊。
- 初次合成產報 exit 0，四來源明示為合成資料；示範自動更新預設關閉。
- 已按明確檔案清單複製，排除公司快照、原始郵件、憑證、SQLite、執行日誌與原 Git 歷史。文字掃描包含原公司網域、案件代碼、本機絕對路徑及常見 token 格式。這是針對性檢查，不能當作任意內容的保密證明。
- 原本抽出的 117 個來源檔案雜湊保持一致；本批改動只在分享複本。

未驗證：本分享版的真實 API 連線、Windows 原生 Python、其他 WSL 發行版、瀏覽器視覺操作、多人正式部署。

首次受限環境測試曾被禁止 localhost socket；允許隔離本機 HTTP 後已重跑全套。沒有用放寬測試標準掩蓋來源或保存錯誤。
